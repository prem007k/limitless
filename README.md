# Limitless - Algorithmic Trading Sandbox

A full-stack **real-time algorithmic trading strategy platform** with visual workflow builder, market replay engine, and advanced portfolio simulation.

![Limitless](https://via.placeholder.com/800x400/0a0a0a/00ff9f?text=LIMITLESS)

## ✨ Features

- **Visual Strategy Builder** - Drag & drop node-based strategy creation (React Flow)
- **Real-time Market Replay** - Tick-by-tick simulation with adjustable speed (1x to 100x)
- **Event-Driven Portfolio Engine** - Accurate PnL, holdings, and risk tracking
- **Live Analytics** - Performance metrics during simulation
- **Modern Tech Stack** - MERN + TypeScript + WebSockets ready

## 🛠 Tech Stack

**Frontend:** React, TypeScript, Tailwind CSS, React Flow, Redux Toolkit, Recharts  
**Backend:** Node.js, Express, TypeScript, MongoDB, WebSocket  
**Tools:** Docker-ready, JWT Auth, Zod validation

## 🚀 Quick Start

```bash
# Clone repo
git clone <your-repo-url>
cd limitless

# Backend
cd backend
npm install
npm run dev

# Frontend (new terminal)
cd frontend
npm install
npm start
